Dataset Validation Rules

The uploaded CSV file must contain the following 5 columns:

Date (YYYY-MM-DD) Location Temperature (°C) Humidity (%) Rainfall (mm)
• Non-numeric temperatures or invalid dates will be safely recorded in the Data Quality Report.
• Negative rainfalls or humidity values outside 0-100% are flagged.
• Valid rows are automatically saved to the active database.

    Validation & Quality Rules Implemented

    In accordance with meteorological data engineering principles, raw input is inspected prior to statistical computation:

    1. Date Format Verification: Dates must resolve to a valid calendar date (YYYY-MM-DD). Non-parsable dates are rejected.
    2. Temperature Range (-60°C to 65°C): Non-numeric characters or temperatures outside terrestrial limits are rejected.
    3. Humidity Bounds (0% to 100%): Relative humidity cannot be negative or exceed 100%.
    4. Non-negative Rainfall: Rainfall must be a non-negative floating-point number (≥ 0.0 mm).
